# Carpeta de Proyecto V1 — Bella Piel

Proyecto Informático I (Prof. Cynthia Berea), 4to año Computación, Escuela
Técnica de CABA. Marco pedagógico Buenos Aires Aprende.

## El problema, en dos frases

La gestión de turnos y consultas de un centro de estética depende hoy de la
atención manual del dueño por WhatsApp, lo que le consume horas de trabajo y
produce superposiciones y turnos perdidos. La propuesta es una aplicación
web que automatice la reserva, el cobro de seña y las respuestas frecuentes,
para liberar ese tiempo y reducir los turnos que hoy se pierden.

**Aclaración metodológica**: "Bella Piel" es un caso imaginario armado por
el equipo, no un comercio real relevado. Los datos de partida se inventaron
a propósito para poder recorrer toda la metodología (Árbol de Problemas,
Árbol de Objetivos, MML, requerimientos, maquetado, pitch) con la misma
disciplina que exigiría un caso real, sin depender de un relevamiento que
no era posible hacer en el tiempo del bimestre.
