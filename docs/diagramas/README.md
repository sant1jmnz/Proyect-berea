# Diagramas

Archivos `.drawio` del diseño conceptual (notación de Peter Chen). Se abren en
draw.io (File → Open from → Device) y se acomodan a mano.

| Archivo | Contenido |
|---|---|
| `chen-entidades-y-relaciones.drawio` | Las 27 entidades y las 37 relaciones con sus cardinalidades `(mín,máx)`, **sin atributos**. Azul = bloque de Santiago, naranja = bloque de Bautista, verde = relación. Es un borrador para acomodar a mano |
| `chen-grupo1.drawio` | Grupo 1: Paciente, Profesional, Protocolo, Turno (con las entidades vecinas como borradores en gris) |

Convenciones: rectángulo azul = entidad; rectángulo gris punteado = entidad
que se detalla en otro grupo; rombo = relación; elipse = atributo; atributo
subrayado = clave primaria; elipse punteada = atributo opcional (admite NULL);
`(mín,máx)` junto a cada línea = cardinalidad.
